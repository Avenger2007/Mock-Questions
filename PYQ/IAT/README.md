## How to use the Markdown

- Each file has a page index, source-PDF links, searchable text and the original page image. Pagination means the physical PDF page, not a printed footer number.
- The English files contain **131 page-specific figure/table descriptions** across nine years. These describe what is shown without substituting invented details for unreadable labels.
- Hindi files have their own OCR text and original pages. Their visual guides explicitly reference English page numbers; identical embedded figures are cross-linked where their image digests match. The descriptions are in English.
- OCR ran on **336 pages**: all Hindi pages and all 11 scanned English 2018 pages. OCR can misread question numbers, options, superscripts, Hindi words and chemistry notation; these are searchable reference drafts, not fully proofread or certified accessible transcriptions.
- Use the PDF/page image for exact equations, structural bonds, graph scales and answer options. Downloaded PDFs are unchanged; page images retain diagrams and formulas that text extraction omits.
- The 2026 answer-key ordering must not be used to infer a realistic random key distribution. The final key has not been independently verified.

## Authoring policy

The user requested fixed order on 28 October 2026 for IAT, NEST and COMEDK. Author directly into the intended final sequence; preserve IDs, options and diagram references. `shuffle_test.py` rejects these exams. Random quality-review sampling does not change paper order.

PYQ acquisition is complete for the recovered files, but the IAT topic analysis, approved blueprint, coverage map, exam-specific validator and pilot approval remain separate steps before bulk mock generation.
