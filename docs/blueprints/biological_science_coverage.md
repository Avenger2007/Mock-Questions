# Coverage map — CUET Biological Science, Tests 1–15

Written **before** any test, so that repeats are prevented rather than fixed. Rules:
- Each angle below may be used **at most 3 times in the whole series**, and each time in a **different format and with different content** (different organism, numbers, statement set or pairing). Never the same question.
- The banks were enlarged after Test 4 (rows added at the end of each chapter), because the first banks could not fill 15 tests within the 3-use limit.
- Before writing a test, pick its 50 slots from these banks, then record the test number against each angle used (the "Used in" column). An angle with three entries is closed.
- Every test covers every chapter in the quota of the blueprint (§3).
