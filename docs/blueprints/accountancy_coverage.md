# Accountancy — coverage plan for Tests 1–25

The purpose of this plan is that every sub-topic is tested from a **different angle** in different tests, with no repeated or number-swapped questions. Every test still follows the blueprint (Section A: Unit I 8, Unit II 14, Unit III 5, Unit IV 13; B1 10; B2 10).

## B1 (Analysis of Financial Statements) and B2 (Computerised Accounting) rotation

Each test covers every B1 area at least once: Schedule III heads, analysis tools and limitations, comparative/common-size statements, the four ratio families and the cash flow statement (operating, investing and financing). Each test covers every B2 area: CAS types, features and limitations, codification, AIS, spreadsheet functions and references, pivot tables, errors, depreciation, loan and payroll schedules, and charts.

A different ratio, cash-flow adjustment or spreadsheet application is the **focus** of each test, so numericals never repeat with only the numbers changed.

**Depth progression:** in Tests 1–8, numericals use 1–3 adjustments. In Tests 9–17 they use 3–4 adjustments and closer distractors. In Tests 18–25 they use 4+ adjustments, longer statements and integrated cases.
