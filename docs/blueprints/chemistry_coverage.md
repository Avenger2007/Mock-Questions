# Coverage map — CUET Chemistry, Tests 1–15

Written **before** any test, so that repeats are prevented rather than fixed. Rules:
- Each angle may be used **at most 3 times in the whole series**, each time in a **different format and with different content** (different compound, numbers, statement set or pairing). Numerical angles count each use the same way; change the system and the numbers every time.
- Before writing a test, pick its 50 slots from these banks (least-used first), then record the test number against each angle used ("Used in" column; `mark_chem.py`).
- Every test covers every unit in the quota of the blueprint (§3).
