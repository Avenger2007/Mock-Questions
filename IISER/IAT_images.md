# IAT — image prompts

One entry per question that needs a figure, in the format given in `docs/instructions/IAT_Instructions.md` (section "Images"). Keep entries in test and question order. Every entry must match a question with the same `image_reference`.

All six Test 1 figures are exact deterministic line drawings, generated by `tools/iat/draw_figures.py`, stored in `IISER/images/`. They are part of the manual-review pilot. IDs and filenames must remain stable.
