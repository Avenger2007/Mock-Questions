@@ C1|Recognising types of 2 × 2 matrices|m|m|C|matrix types identify
Match List-I with List-II.

List-I (Matrix)
(A) \(\begin{bmatrix}0&2\\-2&0\end{bmatrix}\)
(B) \(\begin{bmatrix}3&0\\0&3\end{bmatrix}\)
(C) \(\begin{bmatrix}1&4\\4&5\end{bmatrix}\)
(D) \(\begin{bmatrix}1&2\\0&3\end{bmatrix}\)

List-II (Type)
(I) Upper triangular matrix
(II) Scalar matrix
(III) Skew-symmetric matrix
(IV) Symmetric matrix that is not diagonal
A) (A)-(II), (B)-(III), (C)-(IV), (D)-(I)
B) (A)-(III), (B)-(II), (C)-(I), (D)-(IV)
C) (A)-(III), (B)-(II), (C)-(IV), (D)-(I)
D) (A)-(IV), (B)-(II), (C)-(III), (D)-(I)
=
Why: (A) satisfies \(A^T=-A\) with zero diagonal, so it is skew-symmetric (III). (B) is diagonal with equal diagonal entries, so it is scalar (II). (C) equals its transpose and has non-zero off-diagonal entries (IV). (D) has only zeros below the diagonal, so it is upper triangular (I).
Why not the others: (A) swaps the skew-symmetric and scalar matrices. (B) calls the symmetric matrix triangular. (D) calls the skew-symmetric matrix symmetric.

@@ C1|Determinant of a scalar multiple of a 3 × 3 matrix|e|n|B|det kA order 3
If \(A\) is a square matrix of order 3 and \(|A| = 4\), then \(|2A|\) is:
A) \(8\)
B) \(32\)
C) \(16\)
D) \(64\)
=
Given: order \(n = 3\), \(|A| = 4\), \(k = 2\).
Formula: \(|kA| = k^n|A|\)

@@ C1|Inverse of a 2 × 2 matrix using the adjoint|m|n|A|inverse 2x2 adjoint
The inverse of \(A = \begin{bmatrix}2&5\\1&3\end{bmatrix}\) is:
A) \(\begin{bmatrix}3&-5\\-1&2\end{bmatrix}\)
B) \(\begin{bmatrix}3&5\\1&2\end{bmatrix}\)

D) \(\begin{bmatrix}2&-5\\-1&3\end{bmatrix}\)
=

@@ C1|Solving three equations by the matrix method|h|n|D|matrix method 3 variables
The system \(x + y + z = 6\), \(x - y + z = 2\), \(2x + y - z = 1\) is written as \(AX = B\) and solved by \(X = A^{-1}B\). The solution \((x, y, z)\) is:
A) \((3, 2, 1)\)
B) \((2, 1, 3)\)
C) \((1, 3, 2)\)
D) \((1, 2, 3)\)
=

Formula: \(X = A^{-1}B\) exists because \(|A| \ne 0\)
Step 1: \(|A| = 1(1-1) - 1(-1-2) + 1(1+2) = 0 + 3 + 3 = 6 \ne 0\), so the solution is unique.
Step 2: Solving \(A^{-1}B\) (or eliminating): equation 1 − equation 2 gives \(2y = 4\), so \(y = 2\).
Step 3: Then \(x + z = 4\) and \(2x - z = -1\); adding gives \(3x = 3\), so \(x = 1\) and \(z = 3\).

@@ C2|Monotonicity and extrema of x³ − 3x|m|s|B|cubic monotonic extrema statements
For \(f(x) = x^3 - 3x\), consider the following statements:
(A) \(f\) is strictly increasing on \((1, \infty)\).
(B) \(f\) has a local maximum at \(x = -1\).
(C) The local minimum value of \(f\) is \(-2\).
(D) \(f\) is strictly decreasing on \((-\infty, -1)\).
A) (A) and (B) only
B) (A), (B) and (C) only
C) (B), (C) and (D) only
D) (A), (B), (C) and (D)
=
Given: \(f(x) = x^3 - 3x\)
Formula: \(f'(x) = 3x^2 - 3 = 3(x-1)(x+1)\); \(f''(x) = 6x\)
Step 1: \(f' > 0\) for \(x < -1\) and \(x > 1\); \(f' < 0\) for \(-1 < x < 1\). So (A) is true and (D) is false.
Step 2: \(f''(-1) = -6 < 0\), so \(x = -1\) is a local maximum: (B) is true.
Step 3: \(f''(1) = 6 > 0\), so \(x = 1\) is a local minimum with value \(1 - 3 = -2\): (C) is true.
Common mistake: Marking (D) true by reading the sign of \(f'\) between the roots instead of to the left of \(-1\).
Key point: For a cubic with positive leading coefficient, \(f\) rises, falls between the critical points, then rises again.

@@ C4|Order and degree of differential equations|m|s|A|de order degree statements
Consider the following statements:
(A) The order of \(\dfrac{d^2y}{dx^2} + 3\left(\dfrac{dy}{dx}\right)^3 + y = 0\) is 2.
(B) The degree of \(\left(\dfrac{d^2y}{dx^2}\right)^2 + \left(\dfrac{dy}{dx}\right)^3 = x\) is 3.
(C) The degree of \(\dfrac{d^2y}{dx^2} + \sin\left(\dfrac{dy}{dx}\right) = 0\) is not defined.
(D) The order of \(\left(\dfrac{dy}{dx}\right)^3 = x\) is 3.
Which of the statements given above are correct?
A) (A) and (C) only
B) (A), (B) and (C) only
C) (B) and (D) only
D) (A) and (D) only
=
Why: (A) The highest derivative is the second, so the order is 2. (C) The equation is not a polynomial in \(\dfrac{dy}{dx}\) because of the sine, so its degree is not defined.
Why not the others: (B) is false: the degree is the power of the highest-order derivative, \(\left(\dfrac{d^2y}{dx^2}\right)^2\), so it is 2, not 3. (D) is false: the highest derivative is the first, so the order is 1; the cube gives degree 3.
Key point: Order comes from the highest derivative; degree is that derivative's power, defined only for polynomial equations in the derivatives.

@@ M1|Is a linear function on R a bijection?|e|d|C|linear function bijective

=

@@ M1|Equivalence relations on {1, 2, 3} containing (1, 2)|h|n|B|count equivalence relations containing pair

B) \(2\)
C) \(3\)

=
